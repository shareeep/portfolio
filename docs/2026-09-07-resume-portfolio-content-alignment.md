The resume links to `linkedin.com/in/shariffrashid`, while the website uses `linkedin.com/in/shariff-rashid`. Confirm the canonical profile URL, then use it in both places.

### Tighten the second GovTech bullet

Current:

> Instrumented both products with Langfuse tracing and prompt version management, and restructured prompts to improve cache reuse and latency; proposed the same observability pattern across the team's AI applications

Suggested:

> Instrumented both products with Langfuse tracing and prompt versioning, then restructured prompts to improve cache reuse and latency. Proposed the same observability pattern for the team's other AI applications.

This preserves every claim while separating the implementation from the wider proposal.

### Tighten the third iPiD bullet

Current:

> Built a content agent that turns approved research into briefs, articles, social posts, and newsletters, and designed a GTM engine for account enrichment, CRM sync, personalised outreach, and lead nurturing

Suggested:

> Built a content agent that turns approved research into briefs, articles, social posts, and newsletters; designed account workflows for enrichment, CRM sync, personalised outreach, and lead nurturing.

The shorter label removes one layer of jargon without reducing the scope of the work.

## Writing rule

Use the resume to compress evidence. Use the website to explain it. Both versions should preserve the same facts, dates, ownership boundaries, and completion status.
